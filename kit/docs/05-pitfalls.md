# 05. Грабли (обязательный чек-лист)

Собрано на реальных поломках и потерянных сессиях. Читать до правок.

## Железные запреты

1. **Не писать в RX-страницы.** Любая запись (`sw/sb`) по адресу исполняемого
   сегмента = краш плеера. Маркеры/буферы — только в RW, стек или лог-функцию.
2. **Не трогать `view`/контроллеры из non-main-thread** (таймер обложек, cover-поток)
   — крашится. Дампить/логировать из main-thread (клик, рендер) или снаружи
   (`/proc/pid/mem`, `strace`).
3. **Не затирать эталонный бинарь.** `fw/SYSTEM/usr/bin/hiby_player` — база для всех
   патчей. Эксперименты — в `work/test_*/`. После сборки возвращай базу.
4. **Не трогать медиатеку без бэкапа.** `adb pull /data/usrlocal_media.db` перед
   любыми правками; `list_tb_*` — кэш, можно чистить, `MEDIA_TABLE` — нет.

## Ошибки адресации/анализа

5. **VA ≠ file offset.** У V3 `+0x400000`, но конвертируй через program headers;
   ошибка на 0x10000 уже приводила к подмене чужого слота.
6. **Табличные строки.** «Нет xref из кода» ≠ «не используется»: строка может
   лежать в таблице запросов и браться по индексу.
7. **Один литерал — несколько ссылок** (`lui/addiu` в нескольких местах). Менять
   все согласованно, иначе часть вызовов останется на старом запросе.
8. **`jal` затирает `$ra`.** В хук-точке либо восстанавливай `$ra`, либо ставь хук
   так, чтобы это было безопасно (сверяй дизасм обеих сторон).

## Ловушки UI/списков

9. **Кэш списков переживает прошивку.** `list_tb_*` + `MANAGER_TABLE` в `/data`.
   После смены логики списка — сбросить (`tools/examples/clear_list_cache.py`) либо
   «обновление медиатеки», иначе вид переиспользует старые строки.
10. **Патч одной `INSERT`-ветки ломает кэш.** Кэш наполняется циклом из нескольких
    шаблонов подряд (файлы / cue-CD / cue-трек). Смешение старых и новых строк даёт
    «плавающий» мусор между открытиями — менять надо все ветки.
11. **`GROUP BY` в SELECT-списке** шаблона уже приводил к пропаже обложек и
    нечитаемой SD. Безопасная форма — подзапрос `WHERE rowid IN (SELECT MIN(rowid) …)`.
12. **Обложки: путь — `cover+0x114`**, а не `+0x524`; и он разрешается по колонке
    `id` MEDIA_TABLE. Положишь rowid/0 — получишь одну/случайные обложки.
13. **Алфавитная полоска** требует порядок по `character`; маркер «прочего» должен
    быть > `z` (сравнение `COLLATE NOCASE`), иначе цифры/символы встанут не туда.

## Процесс/устройство

14. **adb-канал капризный:** живёт ~3 мин после включения; при отвале `adb kill-server`
    и/или перезагрузка. `killall hiby_player` = перезагрузка.
15. **`strace` умирает вместе с adb-сессией** — держать трейс в той же сессии.
16. **Дампы `dd` часто `I/O error`** — читать кусками по 2048 страниц ровными базами.
17. **`/tmp` хоста бывает tmpfs с квотой** — промежуточные деревья держать в каталоге
    проекта.
18. **`make.sh build` делает `chown 1004:1004`** — не пугайся смены владельца `fw/`;
    обёртки возвращают владельца хоста.
19. **Ghidra 12:** `analyzeHeadless` не запускает PyGhidra-скрипты — используй
    `pyghidra` с `GHIDRA_INSTALL_DIR` (или `ghidra-mcp`).
