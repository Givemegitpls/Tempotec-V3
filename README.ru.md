# Tempotec V3 Analog — модифицированная прошивка

Неофициальная прошивка для плеера **Tempotec V3 Analog**: исправляет неудобства
стокового интерфейса и добавляет недостающие возможности.

## Что из себя представляет мод

Сравнение актуальной версии со стоковым образом.

**Разделы и внешний вид**

- **Во вкладке "Исполнитель альбома" появился уровень альбомов.** Раньше
  категория сразу показывала плоский список треков; теперь, как в «Артистах»:
  автор → его альбомы → треки.
- **Обложки альбомов во вкладках «Артисты» и «Исполнитель альбома».** раньше в
  этих списках обложек не было вовсе.
- **Переключатель «список альбомов ⇄ список треков».** Во вкладках «Артисты» и
  «Исполнители альбома» кнопка в верхней панели переключает вид списка между
  режимами "треки" и "альбомы".
- **Пункт «ADB» в меню «Режим USB-устройства».** Третий режим подключения к пк,
  помимо Аудио и Хранение: поднимает на плеере ADB.

**Поиск**

- **Русские имена ищутся полоской.** Первая буква имени переводится в латиницу
  (Кино → `K`, Дайте танк → `D`, Вольный Путь → `V`); сама полоска осталась
  стоковой (A–Z и «#»).

**Медиатека и содержимое**

- **Совместные исполнители раздельно.** Тег `X;Y` разбирается по `;` на любое
  число авторов — каждый соавтор виден в списке отдельно, совместный альбом
  появляется у каждого. Справедливо как для тега artist, так и для album artist
- **Альбом, открытый через артиста, показывает все треки**, включая совместные
  записи (`X feat. Y`) — раньше часть альбома могла не отображаться.

**Воспроизведение**

- **Обратимый shuffle.** «Назад → вперёд» возвращает ровно тот же трек, повторов
  нет до конца списка. Режимы «по порядку», «повтор списка», «повтор трека» не
  изменены.

## Установка

1. Скопировать образ прошивки в **корень SD-карты**, строго под именем
   **`v3_analog.upt`** (плеер ищет файл именно с таким именем; готовый образ
   лежит в `out/v3_analog.upt`).
2. Вставить карту в плеер.
3. На плеере: **Настройки → «Обновление ПО»** → выбрать файл прошивки.
4. После прошивки один раз выполнить **«Обновление медиатеки»** — прошивка сама
   расставит буквы, разберёт совместных исполнителей и пересоберёт списки
   (компьютер не нужен).

**Откат:** прошить стоковую `v3_analog.upt` (или известную рабочую сборку из
`backup/`) тем же способом.

## Если имена отображаются криво («Й»/«Ё» двумя глифами)

Некоторые теги приходят в разложенной форме Unicode (NFD): `й` = `и` + бревис.
Шрифт плеера комбинирующих знаков не содержит, поэтому такая буква рисуется как
два глифа — «и» с крышечкой справа. Это свойство файлов, а не прошивки, но его
можно починить вложенным скриптом:

```
python3 tools/normalize_unicode.py --apply /путь/к/музыке   # теги + имена файлов
python3 tools/normalize_unicode.py /путь/к/музыке           # dry-run: только показать
```

Скрипт приводит к NFC теги FLAC/MP3 и имена файлов и папок. По умолчанию —
dry-run, ничего не пишет. После правки один раз выполнить на плеере
**«Обновление медиатеки»**, чтобы база подхватила новые теги.

## Сборка

**Что нужно:** Linux, установленный `docker` и стоковая прошивка `v3_analog.upt`
версии `1.3` в корне проекта. Больше ничего ставить в систему не нужно — все
инструменты живут в docker-образе.

```
docker build -t tempotec-fw-tools docker      # один раз
./tools/build_all.sh                          # сборка «с нуля» из стока
```

Готовый образ появится в `out/v3_analog.upt`. Скрипт сам распаковывает сток,
применяет всю цепочку правок бинаря, прогоняет проверки и собирает образ.

Проверка перед прошивкой:

```
python3 tools/verify_build.py fw/SYSTEM/usr/bin/hiby_player --image out/v3_analog.upt
```
